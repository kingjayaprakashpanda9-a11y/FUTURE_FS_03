# 🎓 Bright Future Academy Website

A modern, responsive coaching institute website developed as an internship-level frontend project.

## 📍 About

Bright Future Academy is a coaching institute based in Bhubaneswar that provides preparation for:

- JEE
- NEET
- Class 10 Board Exams
- Class 12 Board Exams

This project showcases a professional educational website with a modern UI, responsive layout, and attractive design.

---

## 🚀 Features

✅ Modern Landing Page

✅ Responsive Design (Mobile, Tablet & Desktop)

✅ Hero Section with Call-to-Action

✅ About Academy Section

✅ Courses Offered

✅ Student Results Section

✅ Contact Section
